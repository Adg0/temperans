Onboarding

Quick Start

Get your habit dashboard running in under two minutes.

1

Open the Habit Dashboard

Click the calendar-check icon in the Obsidian left ribbon, or press Ctrl+P / Cmd+P and run Temperans Habits: Open habit dashboard. On mobile, launch it from the navigation drawer or command palette.

2

Configure Habits or Pick Presets

New vaults start with one clean starter habit (Reading). Open Settings → Temperans Habits → Configure habits to add custom habits, or click Browse presets to enable Sleep, Hydration, Daily steps, Nutrition, Exercise, GitHub contributions, or Typing practice in one click.

3

Log Today's Progress

Click Log today in the dashboard header. Tap quick-entry pills, enter numbers, or type natural durations like 1h 30m, 45m, or 1:30. Multi-entry habits (like books or workouts) support individual session titles and notes.

4

Import Health Connect & API Data (Mobile or Desktop)

Export Android Health Connect metrics to habit-sync-staging.json (or .csv) using the Temperance Companion app, then click Import companion data in Obsidian on either mobile or desktop whenever the staging file is in your vault. If you don't use a cloud vault sync tool between devices, you can also use optional Local Peer Sync over Wi-Fi.

Habit Archetypes & Cadences

Model positive routines, habits you want to quit, and neutral biometric trackers across daily, weekly, monthly, quarterly, or annual schedules.

  • ✓
    Build Habits (Positive Targets)

    Reach daily or periodic milestones (e.g. Read 15 pages, 30 min exercise). Streaks increment when hitting 100% of your target.

  • ✓
    Avoidance Habits (Quit / Limit)

    Minimize slips (e.g. No Junk Food, No Smoking). Clean days (0 slips) build streaks; values above tolerance register slips.

  • ✓
    Zero-Goal Metric Trackers

    Record numerical variables (Weight, Mood, Blood Pressure). Missing a day never penalizes streaks or consistency scores.

Health Connect Bridge

Android Health Connect Staging & Ingestion

Obsidian plugins cannot query Android's native Health Connect APIs directly. Temperance Companion bridges this gap privately: it reads your permission-granted Health Connect metrics (sleep, steps, hydration, nutrition, exercise) and writes a local staging file (habit-sync-staging.json or habit-sync-staging.csv) into your vault folder—with zero internet permissions.

Temperance Companion v0.1.15

Stages Health Connect data into JSON/CSV • 100% Offline • Optional timers & counters

Companion Repo & Guide
1. Temperance Companion exports Health Connect metrics into your vault's staging file.
2. Click "Import companion data" in Obsidian (on mobile or desktop) to ingest staged records into daily Markdown logs.
  • 1
    Export Health Connect to Staging

    Grant read access in Temperance Companion and export the past 7 days to habit-sync-staging.json or .csv inside your Habit Logs folder.

  • 2
    Import on Mobile or Desktop

    Run Import companion data in Obsidian (via Habit actions or Settings). Works directly on mobile or on desktop whenever the staging file is present in your vault.

  • +
    Bonus: Quick Offline Timers & Counters

    Optionally record quick habit timers or rep counters on the go; they are bundled into the same staging file on export.

Optional Device-to-Device Sync

Encrypted Local Peer Sync

Don't use Obsidian Sync, Syncthing, or a cloud drive between your phone and computer? Local Peer Sync is a built-in, zero-cloud alternative that transfers Settings.md and dated daily logs directly over your local Wi-Fi using authenticated AES-256-GCM encryption.

1. Start the temporary host server on desktop.
2. Scan the pairing QR code with your phone camera.
3. Review file differences and choose Send/Receive directions.
4. Stream encrypted note updates over local Wi-Fi.
5. All habit logs and settings verified and up to date.

GitHub Contributions (GraphQL Viewer Calendar)

Sync daily commits, pull requests, and reviews using a personal access token stored in secret storage.

Habit Logs/Settings.md (YAML excerpt) 
- id: github
  name: GitHub contributions
  unit: contributions
  cadence: daily
  enabled: true
  targetHistory:
    - effectiveDate: 2026-01-01
      min: 1
  endpoint:
    sourceName: github
    method: POST
    url: "https://api.github.com/graphql"
    headers:
      Content-Type: "application/json"
      User-Agent: "Temperans-Habits"
    auth:
      type: header
      headerName: Authorization
      secretKey: "temperans-habits-github-token"
      prefix: "Bearer "
    body:
      query: "query($from: DateTime!, $to: DateTime!) { viewer { contributionsCollection(from: $from, to: $to) { contributionCalendar { weeks { contributionDays { date contributionCount } } } } } }"
      variables:
        from: "{{startDateIso}}"
        to: "{{todayIso}}"
    response:
      recordsPath: data.viewer.contributionsCollection.contributionCalendar.weeks.contributionDays
      dateField: date
      valueField: contributionCount
      aggregation: sum

Monkeytype Typing Practice

Aggregate daily test durations into minutes via your Monkeytype ApeKey.

Habit Logs/Settings.md (YAML excerpt) 
- id: typing
  name: Typing practice
  unit: minutes
  cadence: daily
  enabled: true
  targetHistory:
    - effectiveDate: 2026-01-01
      min: 15
  endpoint:
    sourceName: "monkeytype"
    url: "https://api.monkeytype.com/results?onOrAfterTimestamp={{startMillis}}&limit=1000"
    testUrl: "https://api.monkeytype.com/users/currentTestActivity"
    auth:
      type: header
      headerName: Authorization
      secretKey: "temperans-habits-monkeytype-apekey"
      prefix: "ApeKey "
    response:
      recordsPath: "data"
      dateField: "timestamp"
      valueField: "testDuration"
      aggregation: sum
      valueTransform: "divideBy:60"

Astronomy & Space (NASA / JPL)

Record measured sky observations as daily context in your vault.

NASA/JPL Horizons — Geocentric Moon distance at noon UTC 
- id: moon-earth-distance
  name: Moon distance from Earth
  unit: km
  cadence: daily
  enabled: true
  type: tracker
  targetHistory:
    - effectiveDate: 2026-01-01
  endpoint:
    sourceName: nasa-horizons
    method: GET
    url: "https://ssd.jpl.nasa.gov/api/horizons.api?format=json&COMMAND=%27301%27&OBJ_DATA=NO&MAKE_EPHEM=YES&EPHEM_TYPE=OBSERVER&CENTER=500%40399&START_TIME=%27{{today}}%2012%3A00%27&STOP_TIME=%27{{today}}%2012%3A01%27&STEP_SIZE=%271%20d%27&QUANTITIES=20&RANGE_UNITS=KM&CSV_FORMAT=YES"
    response:
      recordsPath: result
      dateField: "{{today}}"
      valuePattern: "\\$\\$SOE[\\s\\S]*?\\r?\\n[^\\r\\n]*?,\\s*([+-]?(?:\\d+(?:\\.\\d*)?|\\.\\d+)(?:[Ee][+-]?\\d+)?)"
      aggregation: latest
NASA/JPL — Near-Earth asteroid & comet close approaches 
- id: small-body-approaches
  name: Near-Earth asteroid and comet approaches
  unit: events
  cadence: daily
  enabled: true
  type: tracker
  targetHistory:
    - effectiveDate: 2026-01-01
  endpoint:
    sourceName: nasa-jpl
    method: GET
    url: "https://ssd-api.jpl.nasa.gov/cad.api?date-min={{startDate}}&date-max={{endDate}}&dist-max=0.05&nea-comet=true&neo=false"
    response:
      recordsPath: data
      dateField: "3"
      aggregation: count

      aggregation: average

  value: 900
  value_unit: seconds
  tests: 15
  source: monkeytype
  imported: []

  sessions:
